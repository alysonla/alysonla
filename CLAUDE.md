## Repository Purpose

This is a [GitHub profile repository](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme) — the special repo whose `README.md` is displayed on the owner's public GitHub profile page (`github.com/alysonla`).

## Structure

The entire content of this repository is a single file:

- `README.md` — rendered directly on the GitHub profile page; supports GitHub Flavored Markdown and emoji shortcodes (`:octocat:`, `📫`, etc.)

## Conventions

- Changes to `README.md` are immediately reflected on the public profile after pushing to `master`.
- No build step, linter, or test suite exists. Validation is visual: inspect the rendered Markdown on GitHub.
- Emoji shortcodes and Unicode emoji are both valid; the existing file mixes both styles.
